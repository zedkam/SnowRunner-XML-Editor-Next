# Безопасность

Не публикуйте в issues и pull request пароли, GitHub-токены, ключи, сохранения
или содержимое личных конфигураций.

Для уязвимостей, затрагивающих приложение или канал обновлений, сначала
создайте приватный контакт с владельцем репозитория `zedkam`, а не публикуйте
рабочий exploit в открытом issue.
