# Architecture contracts

Эта папка содержит нейтральные контракты для постепенной миграции текущих `/modules` и `/renderer` к content-driven архитектуре.

Код здесь не подключён к runtime намеренно: сначала фиксируются идентичность и границы данных, затем контракты интегрируются вертикальными срезами. Не добавляйте сюда Electron, Vue, Cheerio или WinRAR-зависимости.

- `content/` — источник, происхождение, сущности и diagnostics;
- будущий `xml/` — round-trip документ и сохранение неизвестных узлов;
- будущий `application/` — use cases без UI;
- будущий `infrastructure/` — адаптеры main process.
