# Участие в проекте

Проект является продолжением [VerZsuT/SnowRunner-XML-Editor-Desktop](https://github.com/VerZsuT/SnowRunner-XML-Editor-Desktop).

Перед отправкой изменений:

1. установите зависимости командой `npm ci`;
2. запустите `npm run check`;
3. по возможности запустите `npm run lint` и проверку генераторов DLC;
4. опишите в pull request, какие версии игры и DLC проверялись.

Не добавляйте в репозиторий ключи, токены, сохранения игры, личные конфигурации
или извлечённые игровые архивы.
